# 四子棋（Connect Four）

双人对战的 **6 行 × 7 列** 棋盘游戏。棋子按列落下并受重力沉底，任意方向连成 **4** 子即胜。提供控制台版与图形界面版。

## 游戏规则

- 棋盘为 6 行 × 7 列
- 玩家 **X** 先手，双方轮流选择一列落子
- 棋子受重力影响，落到该列最低的空位（纵向落子）
- 任意一方在横、竖或对角线方向连成 **4** 子获胜
- 某一列已满时不能再向该列落子
- 棋盘填满且无获胜者则平局

## 文件说明

| 文件 | 说明 |
|------|------|
| `matrix_placer.py` | 控制台版本（核心逻辑 + 文字界面） |
| `gui_placer.py` | 图形界面版本（tkinter，点击列落子，带下落动画） |

## 教学要点

控制台版可按模块阅读：

1. **棋盘表示** — 二维列表 `' '` / `'X'` / `'O'`（6×7）
2. **重力落子** — 只选列号，从底部向上找第一个空位
3. **输入校验** — 解析列号、检查范围与列是否已满
4. **胜负判定** — 以最近一步为中心，向四个方向统计连子（长度为 4）
5. **主循环** — 选列 → 下落 → 判胜 → 判平 → 换手

GUI 版复用相同判定思路，把输入换成鼠标点击某一列，并用圆片棋子表现下落过程。

## 环境要求

- Python 3.x
- tkinter（仅 GUI 版本需要，多数 Python 安装已自带）

## 运行方式

### 控制台版本

```bash
python matrix_placer.py
```

输入格式：列号（如 `3`）表示在第 3 列落子  
输入 `q` 退出游戏

### 图形界面版本

```bash
python gui_placer.py
```

点击某一列落子，棋子会落到该列最低空位。可用「重新开始」与「退出」。
